# Roadmap

- `WI-001`: turn the proven personal coordinator skill into a portable,
  MIT-licensed public project ready to install and share.

## Next

- Publish the first reviewed release and gather installation feedback.
- Record date-stamped public adoption metrics without telemetry.

## Later

- Evaluate platform-specific adapters only when users provide evidence of need.
- Run an opt-in mobile or cloud-project pilot and publish its exact tested scope
  and limitations; no pilot has been completed yet.

## Parked
