# Codex for Open Source application

OpenAI's current Codex for Open Source program is rolling and discretionary.
The official benefit is described as six months of ChatGPT Pro, which includes
Codex; selection is not guaranteed. Verify requirements immediately before
submitting through the [official program page](https://developers.openai.com/community/codex-for-oss)
and [official application form](https://openai.com/form/codex-for-oss/).

## Evidence to have ready

- A public GitHub profile and this public repository.
- A tagged public release with green validation evidence.
- A maintainer record showing the applicant's primary/core role.
- Recent, genuine maintenance activity: commits, issues, review, and releases.
- Date-stamped adoption evidence such as stars, forks, installations, or
  credible user reports. Never invent metrics.
- Privacy-preserving collection rules and the honest launch baseline in
  [Adoption evidence and feedback](ADOPTION.md).
- A concise explanation of Cody's ecosystem value even if adoption is still
  early: durable state, bounded delegation, fail-closed authority, recovery,
  and portable project coordination.
- The email associated with the applicant's ChatGPT account and the requested
  OpenAI organization ID. Do not record either value in this repository.

## Qualification draft

> Cody is an MIT-licensed Codex coordinator that turns long-running repository
> work into bounded, recoverable tasks with explicit authority, durable state,
> migration checks, and fail-closed validation. I am its primary maintainer and
> use it for active project coordination. Its reusable safety and portability
> contracts help maintainers coordinate coding agents without tying projects to
> one platform, provider, machine, or secret manager.

Update that draft with honest, date-stamped public adoption evidence before
submission. Keep the final qualification response within the form's current
character limit.

## API-credit draft

> Credits would support reproducible issue triage, cross-platform regression
> investigation, adapter review, migration/recovery testing, documentation
> consistency checks, and exact-candidate release validation for Cody.

## Application hygiene

- Submit only accurate public facts and current metrics.
- Do not include private paths, credentials, account details, customer data,
  private repository material, or consultation transcripts.
- Describe the advertised benefit as “six months of ChatGPT Pro with Codex.”
- Do not imply that Cody is affiliated with, endorsed by, or accepted into any
  OpenAI program.
- Save the exact submitted answers and submission date outside the repository.
