# Maintainers

Cody is maintained by community contributors with repository access. GitHub's
current repository permissions are authoritative for who can merge or publish;
this file describes the responsibilities rather than duplicating an unstable
roster.

Maintainers are responsible for:

- reviewing correctness, security, privacy, and portability claims;
- keeping the public documentation aligned with executable behavior;
- protecting contributor and user data;
- maintaining a small, reproducible validation surface; and
- documenting release decisions and known limitations.

Maintainer access is a project stewardship role, not an affiliation with or
endorsement by OpenAI. See [Governance](GOVERNANCE.md) for decision principles
and [Security](SECURITY.md) for vulnerability handling.
